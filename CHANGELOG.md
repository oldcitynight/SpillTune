# Changelog

## V0.0.1 Fire up

SpillTune first public-source release identity: Python package, CLI and Linux deb use version0.0.1.

- Modular adapter contracts, RAM/device slot lifecycle, backward recomputation, projection LoRA/AdamW and content-bound checkpoint/resume.
- Explicit model/storage capability validation, CPU tests and synthetic offline fixtures.
- Standard Python CLI and lightweight Linux launcher using a selected external environment; no embedded PyTorch/CUDA/Python or model payload.
- Source attribution, retained license texts and reproducible packaging tools.

Native Windows/MSI, universal dependency deployment, llama.cpp integration, distributed/full-parameter training and general model quality acceptance are outside this release.
